# agent-context

Local-first Markdown context for AI-assisted software development.

`agent-context` creates simple Markdown files for project focus, quirks, progress, handoffs, and planning notes so humans and AI agents can resume work without losing context.

No database. No service. No lock-in.

## Install

### Local checkout

```sh
git clone https://github.com/rowlandekemezie/agent-context.git
cd agent-context
pnpm install
pnpm run build
node dist/cli.js --help
```

### Link globally while dogfooding

```sh
pnpm install
pnpm run build
pnpm link --global
agent-context --help
```

### Install from GitHub after push

```sh
pnpm add --global github:rowlandekemezie/agent-context
```

or:

```sh
npm install --global github:rowlandekemezie/agent-context
```

## Quick start

```sh
agent-context init
agent-context context
printf 'Finished the first pass. Validation: pnpm test passed.' | agent-context progress append
agent-context handoff create next-session
agent-context doc create architecture storage-layout
```

## Storage

Default location:

```txt
~/.config/agent-context/projects/<project-name>/
```

Generated layout:

```txt
current-focus.md
QUIRKS.md
architecture/
features/
progress-updates/
research/
subtask-handoffs/
  pending/
  completed/
```

Environment overrides:

- `AGENT_CONTEXT_HOME`: storage root, defaults to `~/.config/agent-context/projects`
- `AGENT_CONTEXT_PROJECT`: project name, defaults to the current directory name

## Commands

| Command | Purpose |
|---|---|
| `agent-context --help` / `agent-context help` | Show help |
| `agent-context --version` | Show version |
| `agent-context init` | Create the project memory layout |
| `agent-context info` | Print resolved paths as JSON |
| `agent-context context` | Print focus, quirks, and recent progress |
| `agent-context progress path` | Create/print today’s progress file |
| `agent-context progress list [n]` | List recent progress files |
| `agent-context progress append [file]` | Append progress from a file or stdin |
| `agent-context handoff create <slug>` | Create a handoff template |
| `agent-context handoff list` | List pending handoffs |
| `agent-context handoff consume` | Print pending handoffs and mark them completed |
| `agent-context doc create <feature\|architecture\|research> <slug>` | Create a planning doc |
| `agent-context doc list <feature\|architecture\|research> [n]` | List planning docs |

See [docs/commands.md](docs/commands.md) for examples.
